# BlackJack Game

This is a BlackJack game made with **JavaScript**. You pay against the dealer who will play until their hand is at least 17. This game includes a betting feature to place the objective to get as much money as you can. There are two rounds of betting: the first after initial deal, and one more after the first "hit" (new card).
